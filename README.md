## 🔄 System Workflow

Products move through a **sorting section** where the conveyor system starts automatically. The industrial robotic arm picks the products and positions them for **assembly operations**. Sensor-based detection is used during the process, after which the robot performs assembly tasks and places the products back onto the conveyor. The conveyor then transfers products to the **distribution section**, while the electro-pneumatic system controls the mechanical actuation processes throughout the workflow.

```
1. Sensor Detection
       ↓
2. PLC Control
       ↓
3. Conveyor Movement
       ↓
4. Robot Pick & Position
       ↓
5. Assembly Operation
       ↓
6. Return to Conveyor
       ↓
7. Pneumatic Actuation
       ↓
8. Distribution Output
```

### 6-Joint Structure

| Joint | Name | Function |
|-------|------|----------|
| **J1** | Waist | Base rotation — Left / Right swing |
| **J2** | Shoulder | Upper arm pivot — Forward / Backward |
| **J3** | Elbow | Forearm pivot — Up / Down motion |
| **J4** | Wrist Roll | Forearm rotation — Twist / Roll axis |
| **J5** | Wrist Pitch | End-effector tilt — Up / Down bend |
| **J6** | Wrist Yaw | Tool flange spin — Final rotation axis |
